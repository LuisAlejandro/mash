Fresh 0.5.7

This download includes fresh-0.5.7-patched.tar.gz: the complete corresponding
source of the Fresh 0.5.7 binary shipped in Mash.app, under the GNU General
Public License, version 3 or (at your option) any later version.

Mash changes six things in that source, and all patches are in the archive
and in Mash's public repository (packaging/patches/):

  - fresh-config-dir.patch     take the config and data directories from
                               MASH_FRESH_CONFIG_DIR and MASH_FRESH_DATA_DIR
                               so Mash can isolate them
  - fresh-reveal-in-finder.patch
                               add "Reveal in Finder" to the file explorer
                               context menu
  - fresh-warn-logs.patch      default diagnostics to WARN while honoring
                               RUST_LOG for opt-in debugging
  - fresh-explorer-clipboard.patch
                               share the file explorer's copy/cut clipboard
                               between Fresh processes through the data
                               directory
  - fresh-daemon-explorer.patch
                               open the file explorer when a `fresh -a` daemon
                               creates its editor, as `fresh .` already does
  - fresh-daemon-idle-timeout.patch
                               let a session reap itself once its last terminal
                               detaches, through FRESH_DAEMON_IDLE_TIMEOUT

GPL-3.0 section 5(a) asks that a modified work carry prominent notices stating
that it was changed, and when.
The patched source files under crates/*/src carry dated "Modified by Mash"
comments for that reason. The other patched files -- the JSON locale
crates/fresh-editor-core/locales/en.json, which cannot carry a comment, and the
test files under crates/fresh-editor/tests -- are recorded by the patches in the
archive.

The archive is the exact source the binary was built from, patches included,
together with the build files Mash used, so it needs no separate offer.
