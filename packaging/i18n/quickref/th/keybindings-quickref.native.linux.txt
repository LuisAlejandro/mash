Mash on Linux — แป้นพิมพ์ (Native)

เครื่องมือแต่ละชนิดใช้ปุ่มของตัวเอง Herdr ใช้คำนำหน้า Ctrl+B ที่มีมา: กด
Ctrl+B ปล่อย แล้วกดปุ่มถัดไป Ctrl+B ไม่ถึงบาน ดังนั้น Ctrl+B ของ Fresh
(ตัวสำรวจไฟล์) Ctrl+B ของ Pi (เคอร์เซอร์ซ้าย) และ Ctrl+B ของ OpenCode
(เซสชันพื้นหลัง) ใช้ไม่ได้ ใช้ Ctrl+E หรือเมนูใน Fresh และลูกศรซ้ายใน Pi

  ── Herdr (Ctrl+B แล้วต่อ) ──
  n / p            แท็บถัดไป / ก่อนหน้า
  c                แท็บใหม่
  1..9             สลับไปแท็บ N
  Shift+T          เปลี่ยนชื่อแท็บ
  Shift+X          ปิดแท็บ
  h j k l          ไปที่บาน ซ้าย / ล่าง / บน / ขวา
  Shift+H J K L    สลับบาน ซ้าย / ล่าง / บน / ขวา
  Tab / Shift+Tab  บานถัดไป / ก่อนหน้า
  v / -            แยกแนวตั้ง / แนวนอน
  x                ปิดบาน
  z                ขยายบาน
  r                ปรับขนาด
  [                โหมดคัดลอก
  e                แก้ไขประวัติการเลื่อน
  Shift+P          เปลี่ยนชื่อบาน
  w                เลือกพื้นที่ทำงาน (มาตรฐาน)
  Shift+W          เปลี่ยนชื่อพื้นที่ทำงาน
  Shift+D          ปิดพื้นที่ทำงาน
  g                ไปที่เซสชัน
  b                สลับแถบข้าง
  o                เปิดการแจ้งเตือน
  s                การตั้งค่า
  Shift+R          โหลดการตั้งค่าใหม่
  q                แยกออก
  ?                วิธีใช้

  ── ส่วนเพิ่มของ Mash (Ctrl+B แล้วต่อ) ──
  t                แท็บพัฒนาใหม่ (เอดิเตอร์ + เอเจนต์)
  a                แท็บเอเจนต์ใหม่
  Shift+C          แท็บเชลล์ใหม่
  Shift+V          แท็บรีวิวใหม่ (diff + เอเจนต์)
  `                บานหน้าต่างเชลล์ใหม่ใต้ Fresh
  f                ค้นหาไฟล์
  y                ควบคุมเวอร์ชัน
  Shift+O          สถานะคอนเทนเนอร์
  Shift+S          สนิปเพต
  i                ใส่คำอธิบายในข้อความ
  Shift+I          วางคำอธิบายให้เอเจนต์ของแท็บนี้
  m                จัดการคำอธิบาย
  u                เลือกลิงก์หรือ ID
  Shift+U          ตัวจัดการปลั๊กอิน
  Shift+Z          ตรวจหาการอัปเดต
  Shift+N          พื้นที่ทำงานใหม่ (โปรไฟล์เลย์เอาต์)
  Shift+G          เวิร์กทรีใหม่ (โปรไฟล์เลย์เอาต์)
  Shift+F          เลือกพื้นที่ทำงาน (เซสชัน)
  ;                พาเลตคำสั่ง
  Shift+Y          แยกเอเจนต์จากข้อความ
  Shift+E          ค้นหาเซสชัน
  Ctrl+F           ค้นหาไฟล์และการกระทำ
  Ctrl+Y           แยกเอเจนต์ไว้ข้างพาเนล
  Ctrl+Shift+Y     แยกเอเจนต์ไปยังเวิร์กสเปซใหม่
  {                พื้นที่ทำงานก่อนหน้า
  }                พื้นที่ทำงานถัดไป
  Shift+↑          เอเจนต์ก่อนหน้า
  Shift+↓          เอเจนต์ถัดไป

  Shift+→          ย้ายแท็บไปทางขวา
  Shift+Backspace  เอาวอร์กทรีออก
  Ctrl+K           ล้างพาเนล

  ── Fresh (ปุ่มเริ่มต้นของตัวเอง) ──
  Ctrl+S           บันทึก
  Ctrl+O           เปิดไฟล์
  Ctrl+P           เปิดด่วน
  Ctrl+F           ค้นหา
  Alt+A            ค้นหาและแทนที่
  F3 / Shift+F3    ค้นหาถัดไป / ก่อนหน้า
  Ctrl+G           ไปที่บรรทัด
  Ctrl+D           เคอร์เซอร์ที่รายการถัดไป
  Ctrl+E           ไปที่ตัวสำรวจไฟล์
  Ctrl+Z / Ctrl+Y  เลิกทำ / ทำซ้ำ

  ── Pi (ปุ่มเริ่มต้นของตัวเอง) ──
  Ctrl+↑ / Ctrl+↓  ไปที่ข้อความก่อนหน้า / ถัดไป

Pi รับ Ctrl+Shift+↑/↓ สำหรับสิ่งนี้เช่นกัน
แต่เทอร์มินัลใช้สองปุ่มนั้นกับการกระโดดพร๊อมพต์ของตัวเอง ดังนั้นใน Native
มันไม่ถึง Pi ใช้ Ctrl+↑/↓ ปุ่มอื่นของ Pi ยังคงเหมือน

คัดลอก / วางในเทอร์มินัล: Ctrl+Shift+C / Ctrl+Shift+V หรือใช้เมาส์ นอกจากนั้น
Pi และเชลล์ใช้ปุ่มเริ่มต้นของตัวเอง
