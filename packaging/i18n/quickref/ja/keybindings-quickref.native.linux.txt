Mash on Linux — キーボード（Native）

各ツールは自分のキーを使います。Herdr は標準の Ctrl+B
プレフィックスで動きます。Ctrl+B を押して離し、その後キーを押します。Ctrl+B
はペインに届かないので、Fresh の Ctrl+B（ファイルエクスプローラー）、Pi の
Ctrl+B（カーソル左）、OpenCode の
Ctrl+B（バックグラウンドセッション）は使えません。Fresh は Ctrl+E
かメニューを、Pi は左矢印を使ってください。

  ── Herdr（Ctrl+B のあと） ──
  n / p            次 / 前のタブ
  c                新しいタブ
  1..9             タブ N へ切り替え
  Shift+T          タブの名前を変更
  Shift+X          タブを閉じる
  h j k l          ペインを左 / 下 / 上 / 右へ
  Shift+H J K L    ペインを左 / 下 / 上 / 右と入れ替え
  Tab / Shift+Tab  次 / 前のペイン
  v / -            縦 / 横に分割
  x                ペインを閉じる
  z                ペインをズーム
  r                サイズ変更
  [                コピーモード
  e                スクロール履歴を編集
  Shift+P          ペインの名前を変更
  w                ワークスペース選択（標準）
  Shift+W          ワークスペースの名前を変更
  Shift+D          ワークスペースを閉じる
  g                セッションへ移動
  b                サイドバーを切り替え
  o                通知を開く
  s                設定
  Shift+R          設定を再読み込み
  q                切り離す
  ?                ヘルプ

  ── Mash の追加（Ctrl+B のあと） ──
  t                新しい開発タブ（エディター＋エージェント）
  a                新しいエージェントタブ
  Shift+C          新しいシェルタブ
  Shift+V          新しいレビュータブ（diff＋エージェント）
  `                Fresh の下に新しいシェルペイン
  f                ファイル検索
  y                バージョン管理
  Shift+O          コンテナの状態
  Shift+S          スニペット
  i                テキストに注釈を付ける
  Shift+I          注釈をこのタブのエージェントに貼り付け
  m                注釈を管理
  u                リンクまたは ID を選択
  Shift+U          プラグイン管理
  Shift+Z          アップデートを確認
  Shift+N          新しいワークスペース（レイアウトプロファイル）
  Shift+G          新しいワークツリー（レイアウトプロファイル）
  Shift+F          ワークスペース選択（セッション）
  ;                コマンドパレット
  Shift+Y          メッセージからエージェントを分岐
  Shift+E          セッション検索
  Ctrl+F           ファイルとアクションを検索
  Ctrl+Y           ペインの横にエージェントを分岐
  Ctrl+Shift+Y     新しいワークスペースにエージェントを分岐
  {                前のワークスペース
  }                次のワークスペース
  Shift+↑          前のエージェント
  Shift+↓          次のエージェント
  Shift+←          タブを左へ移動
  Shift+→          タブを右へ移動
  Shift+Backspace  ワークツリーを削除
  Ctrl+K           ペインをクリア

  ── Fresh（標準のキー） ──
  Ctrl+S           保存
  Ctrl+O           ファイルを開く
  Ctrl+P           クイックオープン
  Ctrl+F           検索
  Alt+A            検索と置換
  F3 / Shift+F3    次 / 前を検索
  Ctrl+G           行へ移動
  Ctrl+D           次の一致へカーソル
  Ctrl+E           ファイルエクスプローラーへ
  Ctrl+Z / Ctrl+Y  元に戻す / やり直す

  ── Pi（標準のキー） ──
  Ctrl+↑ / Ctrl+↓  前 / 次のメッセージへ

Pi は Ctrl+Shift+↑/↓
でもこれを受け付けますが、ターミナルがその二つを自分のプロンプト移動に使うため、Native
では Pi に届きません。Ctrl+↑/↓ を使ってください。他の Pi
のキーはそのままです。

ターミナルのコピー / 貼り付け: Ctrl+Shift+C /
Ctrl+Shift+V、またはマウス。それ以外は Pi とシェルが自分の標準キーを使います。
