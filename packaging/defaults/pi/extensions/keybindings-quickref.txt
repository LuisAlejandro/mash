── Workspaces ──
  ⌘⌃N        New workspace (layout profile picker)
  ⌘⌃⇧N       New worktree (layout profile picker)
  ⌘⌃R        Rename workspace
  ⌘⌃W        Close workspace
  ⌘⌃⌫        Remove worktree
  ⌘⌃[ / ⌘⌃]  Previous / next workspace
  ⌘⌃1-9      Switch to workspace N
  ⌘⌃G        Goto (session navigator)
  ⌘⌃O        Workspace picker (sessions / workspaces)

── Tabs ──
  ⌘T / ⌘⇧N   New dev tab (editor + agent)
  ⌘⌥T / ⌘⌥N  New agent tab
  ⌘⇧R        New review tab (diff + agent)
  ⌘⇧T        New plain shell tab
  ⌘⇧[ / ⌘⇧]  Previous / next tab
  ⌘⇧1-9      Switch to tab N
  ⌘⇧M        Rename tab
  ⌘⇧W        Close tab

── Panes ──
  ⌘⌥← ↓ ↑ →  Focus pane left / down / up / right
  ⌘⌥[ / ⌘⌥]  Cycle pane previous / next
  ⌘⌥\ ⌘⌥-    Split vertical / horizontal
  ⌘⌥W        Close pane
  ⌘⌥Z        Zoom pane
  ⌘⌥R        Resize mode

── Agents ──
  ⌃⇧↑ / ⌃⇧↓  Previous / next agent
  ⌃⇧1-9      Focus agent N

── Addons ──
  ⌃⇧G        Source control
  ⌘⇧O        Container status
  ⌘⌥P        Snippets (snippet executor)
  ⌘P         File finder
  ⌘⇧P        Command palette
  ⌘⌥L        Session search
  ⌘K / ⌘L    Annotate -- capture / paste & archive
  ⌘⇧L        Annotate -- manage
  ⌥G         Pick link or ID
  ⌘⇧X        Plugin manager
  ⌘⌥Y        Fork agent from message
